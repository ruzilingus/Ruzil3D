# Ruzil3D

Данная библиотека предоставляет программные инструменты для математического моделирования различных процессов, а также для численного и аналитического решения математических задач разного уровня.

Представленные программные инструменты затрагивают многие разделы математики, такие как математический анализ, геометрия, вычислительная математика, а также дисциплины: аналитическая геометрия, линейная алгебра, теория элементарных функций.

Библиотека в первую очередь предназначена для инженеров-разработчиков компьютерных игр, но также будет полезна тем разработчикам, которые часто сталкиваются с однотипными математическими задачами в повседневной работе.

# С чего начать

Чтобы начать работу, добавьте <strong>Ruzil3D.dll</strong> в набор ссылок вашего проекта и используйте пространство имён <em>Ruzil3D</em>, чтобы обращаться к инструментам. Библиотека содержит следующие пространства имён:

<ul>
<li><p><em>Ruzil3D</em> – класс <em>Math</em>: константы, обёртки над стандартными математическими функциями, НОД, округление.</p></li>
<li><p><em>Ruzil3D.Algebra</em> – объединяет алгебраические системы, такие как числа, в том числе комплексные и дробные, векторы, кватернионы, матрицы, многочлены.</p></li>
<li><p><em>Ruzil3D.Geometry</em> – содержит геометрические сущности и структуры: различные пространственные преобразования, геометрические фигуры, а также их отношения и операции над ними.</p></li>
<li><p><em>Ruzil3D.Curves</em> – содержит классы и методы для работы с различными кривыми в трёхмерном евклидовом пространстве, преимущественно параметрическими, гладкими, а также абстрактными.</p></li>
<li><p><em>Ruzil3D.Calculus</em> – численное интегрирование и дифференцирование, поиск корней функций, решение систем линейных уравнений, многочлены Лежандра.</p></li>
<li><p><em>Ruzil3D.Approximation</em> – содержит различные абстракции и реализации для аппроксимирования и интерполирования функций.</p></li>
<li><p><em>Ruzil3D.Filters</em> – объединяет инструменты корреляции и сглаживания данных измерений.</p></li>
<li><p><em>Ruzil3D.Utility</em> – вспомогательные инструменты: строковое представление чисел в виде дробей и выражений с константами (π/4, 2√2), высокоточный счётчик времени.</p></li>
</ul>

Структуры, классы и другие типы данных, используемые в разных пространствах имён, зависят друг от друга. Так, например, геометрические объекты и другие пространственные структуры зависят от алгебраических систем, инструменты для работы с кривыми – от геометрических преобразований. В этом смысле библиотека является замкнутой и, как следствие, самодостаточной.

Многие прикладные математические задачи можно успешно решить и запрограммировать на языке структур и классов, описанных в данной библиотеке.

Класс <em>Ruzil3D.Math</em> называется так же, как <em>System.Math</em>. Если в файле подключены оба пространства имён, <em>System</em> и <em>Ruzil3D</em>, обращайтесь к нужному классу по полному имени или через псевдоним, например `using RMath = Ruzil3D.Math;`.

# Сборка и тесты

Для сборки нужен .NET SDK 8 или новее; работает на Windows, Linux и macOS:

```
dotnet build Ruzil3D.sln -c Release
dotnet test Ruzil3D.sln -c Release
```

Библиотека собирается под две платформы: `net35` (.NET Framework 3.5 и старые версии Unity) и `netstandard2.0` (Unity 2018+, .NET Core и .NET 5+). Тесты лежат в проекте `Ruzil3D.Tests` и автоматически запускаются в GitHub Actions при каждом изменении ветки `master` и в пулл-реквестах.

Тесты в `Ruzil3D.Tests` проверяют сборку `netstandard2.0` на .NET 8. Те же тесты для сборки `net35` собираются проектом `Ruzil3D.Tests.NetFramework` (.NET Framework 4.8) и запускаются консольным исполнителем xUnit: в Windows напрямую, в Linux и macOS — через Mono (так они запускаются и в GitHub Actions):

```
dotnet build Ruzil3D.Tests.NetFramework -c Release
mono ~/.nuget/packages/xunit.runner.console/2.9.2/tools/net472/xunit.console.exe Ruzil3D.Tests.NetFramework/bin/Release/net48/Ruzil3D.Tests.NetFramework.dll -appdomains denied -noshadow
```

Пакет NuGet с обеими сборками и XML-документацией собирается командой:

```
dotnet pack Ruzil3D.csproj -c Release -o artifacts
```

Историю изменений см. в файле [CHANGELOG.md](CHANGELOG.md).
